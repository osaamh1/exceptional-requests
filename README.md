# بوابة الطلبات الاستثنائية — كلية الشريعة والدراسات الإسلامية

## الملفات

| الملف | الوظيفة |
|---|---|
| `schema.sql` | قاعدة البيانات كاملة: الجداول، الصلاحيات، دالتا التقديم والتتبع، حاوية المرفقات |
| `index.html` | صفحة الطالب: تقديم الطلب (4 خطوات) + متابعة الطلب |
| `poster.html` | ملصق A4 بالباركود يُعلّق في المكتب |

## خطوات النشر (حوالي 15 دقيقة)

### 1) قاعدة البيانات
1. أنشئ **منظمة جديدة** (New organization ← خطة Free) باسم مثل `Sharia Requests`، ثم أنشئ المشروع `exceptional-requests` **داخلها**.
   > مهم: في الخطة المجانية مساحة الملفات (1 GB) ونقل البيانات (5 GB/شهر) تُحسب على مستوى المنظمة، فالمنظمة المستقلة تضمن ألا تقاسم منصة المتابعة مساحتها.
   > الحد: مشروعان مجانيان نشطان على الحساب كله.
2. افتح **SQL Editor** والصق محتوى `schema.sql` كاملاً، ثم **Run**.
3. من **Project Settings → API** انسخ: `Project URL` و `anon public key`.

### 2) الصفحة
1. افتح `index.html` وضع القيمتين في `CONFIG` أعلى السكربت:
   ```js
   SUPABASE_URL: 'https://xxxx.supabase.co',
   SUPABASE_ANON_KEY: 'eyJhbGciOi...',
   ```
2. أنشئ مستودعاً جديداً في GitHub (مثلاً `exceptional-requests`) وارفع الملفات الثلاثة.
3. **Settings → Pages → Deploy from branch → main**.
4. الرابط الثابت سيكون: `https://<اسم-حسابك>.github.io/exceptional-requests/`

### 3) الموظفون
1. **Authentication → Users → Add user** لكل موظف (بريد + كلمة مرور).
2. انسخ الـ UUID لكل مستخدم ونفّذ:
   ```sql
   insert into public.profiles (id, full_name, role) values
   ('<uuid>', 'اسم مدير النظام', 'admin'),
   ('<uuid>', 'اسم موظف المكتب', 'office'),
   ('<uuid>', 'سعادة العميد',     'dean');
   ```

### 4) الملصق
افتح `https://<حسابك>.github.io/exceptional-requests/poster.html` ← تأكد من الرابط ← **طباعة**.

## الاختبار قبل الإطلاق
- [ ] قدّم طلباً تجريبياً بمرفق من الجوال، وتأكد من ظهور الرقم المرجعي (EX-1448-0001).
- [ ] تتبّع الطلب بالرقم وآخر 4 أرقام.
- [ ] في Supabase → Table Editor تأكد من وصول الطلب في `requests` والمرفق في `request_files`.
- [ ] جرّب رابط مرفق من Storage: يجب ألا يفتح بدون تسجيل دخول (الحاوية خاصة).

## الحماية المطبّقة
- الطالب **لا يصل للجداول إطلاقاً**؛ يتعامل فقط مع دالتين محدودتين (تقديم/تتبع).
- التتبع لا يكشف أي ملاحظة داخلية — الحالة ورسالة الطالب فقط.
- المرفقات في حاوية خاصة: الطالب يرفع ولا يقرأ، والموظفون فقط يطّلعون.
- حد 3 طلبات لكل رقم جامعي خلال 24 ساعة، و5 مرفقات بحد 10MB للملف.
- **ضغط الصور تلقائياً في جهاز الطالب** قبل الرفع (أطول ضلع 1800 بكسل، JPEG بجودة 80%): صورة الجوال المعتادة تنزل من 3–5MB إلى ما بين 200 و500KB تقريباً وتبقى واضحة للقراءة. ملفات PDF وWord تُرفع كما هي. الإعدادات في `CONFIG` أعلى السكربت.
- الترقيم بالسنة الهجرية تلقائياً ويبدأ من جديد كل سنة.
